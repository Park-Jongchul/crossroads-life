# 갈림길 — 살아보지 않은 나

[게임 플레이](https://park-jongchul.github.io/crossroads-life/)

0세부터 85세까지 시간이 흐르는 한국어 인생 시뮬레이션입니다.

- 기본 1년 60초, 1~8배속, 일시정지, 화면을 떠나면 정지
- 45종 생애·무작위 사건과 상황에 따른 선택, 6가지 생활 방향
- 12가지 활동, 진로·구직·가족·반려동물·집과 자동차
- 월별 수입·생활비·부채, 적금 12/24/36개월과 중도 해지
- 가상 주식 2종과 코인, 월별 가격·차트·매수·매도·수수료
- 한 번의 되감기와 같은 나이의 두 삶 비교
- 브라우저 자동 저장·이어하기·인생 서랍·JSON 내보내기

HTML/CSS/JavaScript만 사용합니다. GitHub Pages는 main 브랜치의 루트를 제공합니다. 서버나 계정은 필요하지 않습니다. 모든 시장·금리·자산·사건은 게임을 위한 허구이며 실제 투자 상품과 무관합니다.

v1의 기록은 별도 저장 키에 보존됩니다. 진행 중인 v1 인생은 v2 월 단위 모델로 변환하지 않습니다. 완주한 v1 기록은 인생 서랍에서 볼 수 있습니다.

## 검증

`node tests/verify-sim.cjs`
